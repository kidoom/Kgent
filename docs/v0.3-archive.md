## 3. 核心组件

### 3.1 Span + Tracer (D1)

**Span** 是链路追踪的基本单元，形成树形结构：

```python
from kagent.core.tracing import Span, SpanType, SpanStatus, Tracer

tracer = Tracer()  # 单例
root = tracer.start_trace("ReActAgent.run", input_text="北京天气")

with tracer.span("llm.call", SpanType.LLM_CALL) as s:
    response = llm.invoke(messages)
    # 自动记录 duration_ms，异常时自动设 status=ERROR

tracer.end_trace(root)
```

**SpanType 枚举：**

| 类型 | 用途 |
|------|------|
| `AGENT_RUN` | Agent.run() 根 span |
| `AGENT_STEP` | 推理循环的每一步 |
| `LLM_CALL` | LLM 调用 |
| `TOOL_CALL` | 工具调用 |

**并发隔离：** 使用 Python `contextvars`，多线程/async 不会串 trace。

### 3.2 TraceExporter (D2)

三种导出格式：

```python
from kagent.core.tracing import TraceExporter

# 1. dict — 程序化访问
d = TraceExporter.to_dict(root_span)

# 2. JSON — 含汇总统计
json_str = TraceExporter.to_json(root_span)
# {
#   "name": "ReActAgent.run",
#   "total_tokens": {"prompt": 770, "completion": 183, "total": 953},
#   "total_duration_ms": 2630.5,
#   "tool_call_count": 2,
#   ...
# }

# 3. 终端树形图
print(TraceExporter.to_tree(root_span))
# ├── ReActAgent.run [2630.5ms]
#   ├── step.0 [1680.0ms]
#     ├── llm.call.step0 [1230.0ms] tokens:320/85
#     └── tool.call.Search [450.0ms]
```

### 3.3 Agent 埋点 (D3)

所有 Agent 范式支持 `enable_tracing=True` 参数：

```python
from kagent import ReActAgent, AgentLLM, Config

agent = ReActAgent(name="qa", llm=llm, tool_registry=registry)
result = agent.run("北京天气")

# 自动产生的 trace 结构：
# AGENT_RUN "qa.run"
#   ├── AGENT_STEP "step.0"
#   │   ├── LLM_CALL "llm.call.step0"  ← 含 token_usage
#   │   └── TOOL_CALL "tool.call.Search"
#   └── AGENT_STEP "step.1"
#       └── LLM_CALL "llm.call.step1"

from kagent.core.tracing import Tracer, TraceExporter
trace = Tracer().get_all_traces()[-1]
print(TraceExporter.to_tree(trace))
```

禁用追踪：`ReActAgent(..., enable_tracing=False)`

### 3.4 MCPTool (D4)

MCP (Model Context Protocol) 客户端，通过子进程 + JSON-RPC 2.0 与外部 MCP Server 通信：

```python
from kagent.tools.mcp_tool import MCPTool
from kagent.tools.registry import ToolRegistry

# 连接 MCP Server
mcp = MCPTool(server_command=["python", "my_rag_server.py"])
mcp.connect()

# 发现远程工具
tools = mcp.discover_tools()  # → [Tool("search_docs"), Tool("list_sources")]

# 调用远程工具
result = mcp.call_tool("search_docs", {"query": "Kagent"})
# → ToolResult(content="...", success=True)

# 或注册到 ToolRegistry（自动发现 + 批量注册）
registry = ToolRegistry()
registry.register_mcp(mcp)  # → ["search_docs", "list_sources"]
registry.execute_tool("search_docs", {"query": "test"})
```

**自动重连：** 子进程断开时自动重连（最多 3 次，30s 超时）。

### 3.5 MCP Server 模板 (D5)

`kagent/tools/mcp_server_template.py` — 可直接运行的 MCP Server 示例：

```bash
# 启动 MCP Server
python -m kagent.tools.mcp_server_template
```

暴露两个工具：
- `search_docs` — 搜索文档库
- `list_sources` — 列出可用文档来源

可作为 RAG 项目接入 Kagent 的参考模板。

### 3.6 ToolRegistry 线程安全 (D6/D7)

`register_tool()` / `unregister()` / `disable()` / `enable()` / `execute_tool()` 全部加 `threading.Lock`：

```python
# execute_tool 内部：先取快照，再执行
with self._lock:
    tool = self._tools.get(name)
    is_disabled = name in self._disabled
# 快照之后即使其他线程 unregister，也不影响本次执行
```

新增 `register_mcp()` 方法，自动发现 + 批量注册：

```python
registry.register_mcp(mcp_tool)  # → ["tool_a", "tool_b"]
```

### 3.7 容错机制 (D7)

**LLM 指数退避重试 (L3)：**

```python
# FunctionCallAgent._invoke_with_tools() 内置
# 超时/429 → 1s → 2s → 4s 退避，最多 3 次重试
# 3 次均失败 → 抛 LLMError
```

**SearchTool 幂等缓存 (I1)：**

```python
# 同一 query 5s 内返回缓存结果，不重复发 HTTP
search = SearchTool()
search.run({"query": "Python"})  # → HTTP 请求
search.run({"query": "Python"})  # → 缓存命中，无 HTTP
```

**MCP 自动重连：**

```python
# 子进程断开 → 自动重启 → 重新初始化 → 重试请求
# 最多重连 3 次，超时 30s
```

### 3.8 监控 (D8)

**AgentLLM 自动注入 Token 用量：**

```python
# AgentLLM.invoke() 完成后自动写入当前 Tracer span
# 无需 Agent 手动处理
response = llm.invoke(messages)
# → Tracer.add_event("llm.end", {"token_usage": {prompt, completion, total}})
```

**run_id 贯穿：**

```python
agent.run("test")
# run_id 在 trace root metadata 中
# TraceExporter.to_json() → {"metadata": {"run_id": "a1b2c3d4"}}
```

## 7. 使用示例

### 链路追踪

```python
from kagent import ReActAgent, AgentLLM, Config, ToolRegistry
from kagent.core.tracing import Tracer, TraceExporter

agent = ReActAgent(name="qa", llm=llm, tool_registry=registry)
result = agent.run("北京天气怎么样？")

# 获取 trace 并导出
traces = Tracer().get_all_traces()
print(TraceExporter.to_tree(traces[-1]))
# ├── qa.run [2630.5ms]
#   ├── step.0 [1680.0ms]
#     ├── llm.call.step0 [1230.0ms] tokens:320/85
#     └── tool.call.Search [450.0ms]
#   └── step.1 [950.0ms]
#       └── llm.call.step1 [890.0ms] tokens:450/98
```

### MCP 接入外部 RAG

```python
from kagent.tools.mcp_tool import MCPTool
from kagent.tools.registry import ToolRegistry

mcp = MCPTool(server_command=["python", "my_rag_project/server.py"])
registry = ToolRegistry()
registry.register_mcp(mcp)  # 自动发现并注册所有远程工具

# 现在 Agent 可以像使用本地工具一样使用远程 RAG
agent = ReActAgent(name="rag", llm=llm, tool_registry=registry)
result = agent.run("搜索关于 Kagent 的文档")
```

### Token 用量监控

```python
import json
from kagent.core.tracing import Tracer, TraceExporter

agent.run("复杂问题")
trace = Tracer().get_all_traces()[-1]
data = json.loads(TraceExporter.to_json(trace))

print(f"总 Token: {data['total_tokens']['total']}")
print(f"工具调用: {data['tool_call_count']} 次")
print(f"总耗时: {data['total_duration_ms']}ms")
```
