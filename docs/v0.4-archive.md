## 3. 核心组件

### 3.1 BaseMemory + MemoryManager (E1)

**BaseMemory** 是所有记忆后端的抽象基类：

```python
from kagent.memory import BaseMemory, MemoryItem

class BaseMemory(ABC):
    def store(self, item: MemoryItem) -> None: ...
    def search(self, query: str, top_k: int = 5) -> list[MemoryItem]: ...
    def clear(self) -> None: ...
```

**MemoryManager** 编排多个后端，统一写入与检索：

```python
from kagent.memory import MemoryManager, WorkingMemory, EpisodicMemory

manager = MemoryManager()
manager.register("working", WorkingMemory(capacity=100, ttl=300))
manager.register("episodic", EpisodicMemory())

# 存储到所有后端
manager.store(MemoryItem(content="用户叫张三"))

# 从所有后端合并检索
results = manager.search("张三", top_k=5)

# 或指定后端
results = manager.search("张三", backend="working")
```

### 3.2 WorkingMemory (E2)

短期记忆，带 TTL 和容量限制：

```python
from kagent.memory import WorkingMemory

wm = WorkingMemory(capacity=100, ttl=300)  # 最多 100 条，5 分钟过期
wm.store(MemoryItem(content="当前对话主题"))
wm.search("主题")  # → [MemoryItem(...)]

# 容量满时自动淘汰最旧的 (LRU)
# TTL 过期的条目在 search 时自动清理
```

### 3.3 EpisodicMemory (E2)

时间序列记忆，支持时间范围检索：

```python
from kagent.memory import EpisodicMemory
from datetime import datetime, timezone

em = EpisodicMemory()
em.store(MemoryItem(content="2026年1月发生了X"))
em.store(MemoryItem(content="2026年6月发生了Y"))

# 按时间范围检索
results = em.search(
    "发生", top_k=10,
    after=datetime(2026, 3, 1, tzinfo=timezone.utc),
)
# → 只返回 "2026年6月发生了Y"
```

### 3.4 SemanticMemory (E2.5)

基于向量嵌入的语义检索：

```python
from kagent.memory import SemanticMemory

# 使用自定义 embedding 函数
def my_embed(text: str) -> list[float]:
    # 实际使用中接入 OpenAI / 本地模型
    return [...]

sm = SemanticMemory(embedding_fn=my_embed, similarity_threshold=0.3)
sm.store(MemoryItem(content="Kagent 是一个 AI Agent 框架"))
results = sm.search("智能体框架")  # 语义匹配

# 无 embedding 函数时自动回退到子串匹配
sm = SemanticMemory()
sm.store(MemoryItem(content="hello"))
sm.search("hello")  # → 子串匹配，score=0.5
```

### 3.5 MemoryTool (E3)

将 MemoryManager 封装为 Agent 可用的 Tool：

```python
from kagent.memory import MemoryManager, WorkingMemory, MemoryTool
from kagent.tools import ToolRegistry

manager = MemoryManager()
manager.register("working", WorkingMemory())

registry = ToolRegistry()
registry.register_tool(MemoryTool(manager))

# Agent 可通过以下格式使用：
# [TOOL_CALL:memory:action=remember,content=用户叫张三]
# [TOOL_CALL:memory:action=recall,query=用户的名字]
```

### 3.6 ContextBuilder (E4)

GSSC 上下文构建流水线：

```python
from kagent.context import ContextBuilder

builder = ContextBuilder(max_tokens=4000)

context = builder.build(
    messages=[{"role": "user", "content": "北京天气"}],
    tool_results=["北京晴, 25°C"],
    memories=["用户在北京工作"],
    min_score=0.5,  # 过滤低分记忆
)
# → "## 对话历史\nuser: 北京天气\n\n## 工具结果\n北京晴, 25°C\n\n## 相关记忆\n用户在北京工作"
```

**GSSC 四阶段：**

| 阶段 | 方法 | 作用 |
|------|------|------|
| Gather | `gather()` | 收集 messages / tool_results / memories / extra |
| Select | `select()` | 按 min_score 过滤低相关性条目 |
| Structure | `structure()` | 按类型分组格式化为 prompt-ready 文本 |
| Compress | `compress()` | 截断以适应 max_tokens（保留尾部最新内容） |

### 3.7 NoteTool + TerminalTool (E5)

**NoteTool** — 内存笔记 CRUD：

```python
from kagent.tools import NoteTool

tool = NoteTool()
tool.run({"action": "create", "title": "备忘", "content": "记住这个"})
tool.run({"action": "list"})
tool.run({"action": "read", "id": "1"})
tool.run({"action": "update", "id": "1", "content": "更新内容"})
tool.run({"action": "delete", "id": "1"})
```

**TerminalTool** — 只读文件系统访问：

```python
from kagent.tools import TerminalTool

tool = TerminalTool(root_dir="/path/to/project")
tool.run({"action": "list", "path": "."})
tool.run({"action": "read", "path": "README.md"})
```

安全限制：
- 只允许 `list` 和 `read` 操作（不支持 write/delete/execute）
- 路径越界防护（不能访问 root_dir 之外的文件）
- 文件大小限制（最大 10KB）
- 二进制文件检测
