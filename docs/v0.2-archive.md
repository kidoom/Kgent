## 3. 核心组件

### 3.1 多 Provider 支持 (C4)

v0.1 仅支持 OpenAI（含 Ollama/VLLM 兼容），v0.2 扩展至 5 个 Provider：

| Provider | 类 | 默认 base_url | API Key |
|----------|-----|---------------|---------|
| `openai` | OpenAIProvider | `https://api.openai.com/v1` | 必填 |
| `ollama` | OpenAIProvider | `http://localhost:11434/v1` | 可空 |
| `vllm` | OpenAIProvider | `http://localhost:8000/v1` | 可空 |
| `zhipu` | ZhipuProvider | `https://open.bigmodel.cn/api/paas/v4` | 必填 |
| `modelscope` | ModelScopeProvider | `https://api-inference.modelscope.cn/v1` | 必填 |

ZhipuProvider 和 ModelScopeProvider 继承 OpenAIProvider（均为 OpenAI 兼容协议）。

**自动检测 (`auto`)：**

```bash
# .env
LLM_PROVIDER=auto
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
# → 自动识别为 zhipu
```

`_auto_detect()` 启发式规则：
- `localhost:11434` → ollama
- `bigmodel.cn` → zhipu
- `modelscope.cn` → modelscope
- 其他 → openai

```python
from kagent import AgentLLM, Config

# 显式指定
llm = AgentLLM(provider="zhipu", config=Config(api_key="sk-xxx"))

# 自动检测
llm = AgentLLM(provider="auto", config=Config(api_key="sk-xxx", base_url="https://open.bigmodel.cn/api/paas/v4"))
```

### 3.2 ToolRegistry 双注册 (C5)

v0.1 已支持 Tool 对象 + 裸函数双重注册，v0.2 补充验收测试：

```python
registry = ToolRegistry()
registry.register_tool(CalculatorTool())           # Tool 对象
registry.register_function("greet", "Say hi", fn)  # 裸函数

desc = registry.get_tools_description()  # 两者均出现
registry.unregister("greet")             # 两者均可移除
```

### 3.3 PlanAndSolveAgent (B4)

**两阶段推理**：先规划步骤，再逐步执行。

```python
from kagent import PlanAndSolveAgent, AgentLLM, Config

llm = AgentLLM(config=Config(api_key="sk-xxx"))
agent = PlanAndSolveAgent(name="planner", llm=llm)
result = agent.run("分析 Python 和 Go 的优缺点")
```

**执行流程：**

```
用户: "分析 Python 和 Go 的优缺点"
│
├─ Phase 1: Plan
│  LLM → '["Step 1: 分析 Python 优点", "Step 2: 分析 Python 缺点",
│           "Step 3: 分析 Go 优点", "Step 4: 分析 Go 缺点", "Step 5: 总结对比"]'
│  解析: ast.literal_eval → list[str]
│
├─ Phase 2: Execute (逐步)
│  Step 1 → LLM 生成 Python 优点分析
│  Step 2 → LLM 生成 Python 缺点分析（含 Step 1 上下文）
│  Step 3 → LLM 生成 Go 优点分析（含前序进度）
│  ...
│  Step 5 → LLM 生成最终对比总结
│
└─ 返回: 最终总结
```

**容错：** 计划解析失败 → 抛 `AgentError("无法解析执行计划")`

### 3.4 ReflectionAgent (B5)

**迭代优化**：生成答案 → 自我反思 → 改进 → 直到满意。

```python
from kagent import ReflectionAgent, AgentLLM, Config

llm = AgentLLM(config=Config(api_key="sk-xxx"))
agent = ReflectionAgent(name="refiner", llm=llm, config=Config(api_key="sk-xxx", max_steps=3))
result = agent.run("写一个 Python 快速排序")
```

**执行流程：**

```
用户: "写一个 Python 快速排序"
│
├─ Initial: LLM 生成初版快排（可能用试除法）
│
├─ Reflect 1: LLM 反思 → "可以用 Lomuto 分区优化"
│  Refine 1:  LLM 改进为标准快排实现
│
├─ Reflect 2: LLM 反思 → "边界情况未处理"
│  Refine 2:  LLM 添加空列表/单元素处理
│
├─ Reflect 3: LLM 反思 → "无需改进"
│  → 终止循环
│
└─ 返回: 最终优化版本
```

**终止条件：** 反思返回 `"无需改进"` 或达到 `max_steps`。

### 3.5 FunctionCallAgent (B6)

**原生函数调用**：使用 OpenAI 原生 `tool_calls` 协议，非 Prompt 约束。

```python
from kagent import FunctionCallAgent, AgentLLM, Config, ToolRegistry
from kagent.tools.builtin import CalculatorTool, SearchTool

registry = ToolRegistry()
registry.register_tool(CalculatorTool())
registry.register_tool(SearchTool())

llm = AgentLLM(config=Config(api_key="sk-xxx"))
agent = FunctionCallAgent(name="fc_agent", llm=llm, tool_registry=registry)
result = agent.run("同时查北京和上海天气")
```

**与 SimpleAgent/ReActAgent 的区别：**

| 维度 | SimpleAgent | ReActAgent | FunctionCallAgent |
|------|-------------|------------|-------------------|
| 工具调用方式 | Prompt 约束 `[TOOL_CALL:x:y]` | Prompt 约束 `Action: X[y]` | 原生 `tool_calls` |
| 解析方式 | 正则匹配 | 正则匹配 | JSON 结构化 |
| 并行调用 | 不支持 | 不支持 | 支持多个 tool_calls |
| 适用场景 | 简单对话 | 需要推理链 | 支持 function calling 的模型 |

**执行流程：**

```
用户: "同时查北京和上海天气"
│
├─ LLM 返回 tool_calls:
│  [call_1: search(query="北京天气"), call_2: search(query="上海天气")]
│
├─ 并行执行:
│  call_1 → SearchTool → "北京晴, 25°C"
│  call_2 → SearchTool → "上海多云, 22°C"
│
├─ 注入 tool 结果 → LLM 二次调用
│
└─ LLM 返回: "北京今天晴朗 25°C，上海多云 22°C"
```

## 4. Agent 范式总览

v0.2 完成后，5 种范式全部可用：

| 范式 | 文件 | 工作模式 | 适用场景 |
|------|------|---------|---------|
| **SimpleAgent** | `simple_agent.py` | 直接对话 + 可选工具 | 简单对话 |
| **ReActAgent** | `react_agent.py` | Thought→Action→Observation | 需要推理链 |
| **PlanAndSolveAgent** | `plan_solve_agent.py` | Plan→Execute 两阶段 | 结构化推理 |
| **ReflectionAgent** | `reflection_agent.py` | Execute→Reflect→Refine | 高质量生成 |
| **FunctionCallAgent** | `function_call_agent.py` | 原生 tool_calls | 并行工具调用 |

所有范式均：
- 继承 `Agent` 基类，支持 `custom_prompt` 模板变量
- 每次 `run()` 生成 `run_id`（8 位 hex）
- 使用 `Config` 驱动 `max_steps` / `temperature` 等参数
- 工具异常不中断循环（`ToolResult(success=False)` 返回给 LLM）

## 8. 使用示例

### 切换 Provider（零代码改动）

```bash
# 使用智谱
LLM_PROVIDER=zhipu
LLM_API_KEY=your-zhipu-key
LLM_MODEL_ID=glm-4

# 使用 Ollama 本地
LLM_PROVIDER=ollama
LLM_MODEL_ID=qwen2.5

# 自动检测
LLM_PROVIDER=auto
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
```

### 5 种范式快速对比

```python
from kagent import (
    SimpleAgent, ReActAgent, PlanAndSolveAgent,
    ReflectionAgent, FunctionCallAgent,
    AgentLLM, Config, ToolRegistry,
)
from kagent.tools.builtin import CalculatorTool, SearchTool

registry = ToolRegistry()
registry.register_tool(CalculatorTool())
registry.register_tool(SearchTool())

llm = AgentLLM(config=Config(api_key="sk-xxx"))

# 简单对话
SimpleAgent(name="s", llm=llm, tool_registry=registry).run("1+1")

# 推理循环
ReActAgent(name="r", llm=llm, tool_registry=registry).run("北京天气")

# 规划执行
PlanAndSolveAgent(name="p", llm=llm).run("对比 Python 和 Go")

# 反思优化
ReflectionAgent(name="rf", llm=llm).run("写快排函数")

# 原生函数调用
FunctionCallAgent(name="fc", llm=llm, tool_registry=registry).run("同时查北京上海天气")
```
